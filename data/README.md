## 🔍 数据收集方法

### 方法1: 从现有资源转换
如果你有现有的词汇表（Excel、CSV、TXT等），可以：
1. 整理成标准格式
2. 使用脚本批量转换为JSON
3. 人工校对和补充例句

### 方法2: API数据获取
可以使用以下API获取单词数据：
- 有道词典API
- 金山词霸API
- Dictionary API
- Oxford Dictionary API（需付费）

### 方法3: 网络爬虫
从公开词汇网站爬取：
- 注意遵守网站的robots.txt
- 注意版权问题
- 需要清洗和格式化数据

### 方法4: 手工整理（推荐用于测试）
对于小规模测试：
1. 参考 `cet4-sample.json` 的格式
2. 手工添加20-50个单词
3. 确保数据质量高
4. 用于验证导入脚本功能

## 📝 数据准备检查清单

准备每个词书数据文件时，请确保：

- [ ] 文件是有效的JSON格式
- [ ] 使用UTF-8编码
- [ ] 每个单词都有word字段
- [ ] 每个单词至少有一个词性
- [ ] 每个词性至少有一个词义
- [ ] 词义包含definition字段
- [ ] 尽量包含音标（phonetic）
- [ ] 尽量包含例句（examples）
- [ ] difficulty值在1-5范围内
- [ ] 单词使用小写
- [ ] 文件中无重复单词

## 💡 提示

### 使用测试数据
在开发和测试导入脚本时，建议使用小规模数据：
```bash
# 使用测试数据（20词）
npm run import -- --book cet4 --file ./data/cet4-sample.json

# 使用完整数据（3000词）
npm run import -- --book cet4 --file ./data/cet4.json
```

### 数据版本管理
建议使用Git管理数据文件：
```bash
# 添加到版本控制
git add data/*.json

# 提交
git commit -m "Add CET4 vocabulary data"
```

### 数据备份
定期备份重要的词书数据文件，避免数据丢失。

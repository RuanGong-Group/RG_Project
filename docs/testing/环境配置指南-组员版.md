### 2️⃣ 本地Docker环境（推荐：一键启动完整环境）

**这是什么？**  
在你电脑上用Docker一键启动完整环境（前端+后端+MySQL+Redis），**不需要手动装MySQL**。

📦 **前置条件：** 安装 Docker Desktop（Windows版：https://www.docker.com/products/docker-desktop）  
📝 **适用范围：** 所有测试用例（A/F/E/S系列都可以测）  
⚡ **启动方式：** 3条命令搞定（见下方）

**优点：**
- ✅ 不需要手动安装MySQL、Redis
- ✅ 环境隔离，不影响你电脑上的其他项目
- ✅ 接近真实生产环境

**启动步骤：**
```powershell
# 1. 配置环境变量（参考下方"配置清单"填写API密钥）
cd backend
copy .env.example .env
# 编辑 .env 文件，填写 SiliconFlow、豆包、COS、GitHub 密钥
> 适用于：本地Docker环境 + 本地原生环境
# 2. 启动所有容器
cd ..
docker-compose up -d

# 3. 初始化数据库（仅首次启动需要）
docker-compose exec backend npx prisma migrate deploy
docker-compose exec backend npx prisma db seed

# 访问地址（Docker环境）：http://localhost:8080
# 后端API（Docker环境）：http://localhost:4000/api
```

**停止服务：** `docker-compose down`  
**清空数据重测：** `docker-compose down -v` 然后重新执行步骤2-3

⚠️ **注意：** Docker Desktop占用内存较大（建议8GB以上内存的电脑使用）

### 3️⃣ 本地原生环境（适用于深度调试和边界测试）

**为什么需要本地环境？**

📝 **适用范围：**

- **E/S系列（边界/扩展测试）：** E001-E057, S001-S035，测试极端情况和并发场景

**需要安装的软件：**
- Node.js 18+（运行前后端代码）
- MySQL 8.0+（数据库）
- Python 3.8+（视频生成脚本）

**配置步骤：** 见下方详细说明 ↓

### 第二步：配置后端环境变量

打开 `backend/.env` 文件，按照以下说明修改：

```dotenv
# ==================== 基础配置 ====================
PORT=3000
NODE_ENV=development

# ==================== 数据库配置 ====================
# ⚠️ 重要：将 "password" 替换为你本地 MySQL root 用户的真实密码
DATABASE_URL="mysql://root:你的MySQL密码@localhost:3306/vocabulary_db"

# ==================== JWT 配置 ====================
# ✅ 测试环境保持默认即可
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production
JWT_EXPIRES_IN=7d

# ==================== Redis 配置 ====================
# ✅ 可选配置，留空即可（系统自动使用内存存储）
# REDIS_URL=redis://localhost:6379

# ==================== AI 服务配置（需自行申请） ====================
# 📝 SiliconFlow API（用于 DeepSeek 文本生成）
# 申请地址：https://siliconflow.cn/
# 注册后进入"API密钥"页面创建密钥（有免费额度）
SILICONFLOW_API_KEY=【请填写你自己申请的密钥】

# 📝 豆包图像生成 API（火山引擎，视频生成必需）
# 申请地址：https://console.volcengine.com/ark/
# 步骤：注册账号 -> 控制台 -> 模型API -> 创建API密钥（有免费额度）
DOUBAO_API_KEY=【请填写你自己申请的密钥】
# 以下保持默认
# DOUBAO_API_BASE=https://ark.cn-beijing.volces.com/api/v3
# DOUBAO_IMAGE_MODEL=doubao-seedream-4-0-250828
# DOUBAO_IMAGE_STYLE=comic

# ==================== 腾讯云 COS 配置（组长提供） ====================
# ✅ 使用组长提供的以下密钥（视频上传到腾讯云COS）

COS_SECRET_KEY=
COS_BUCKET_NAME=
COS_REGION=ap-guangzhou
COS_UPLOAD_ENABLED=true

# ==================== 腾讯云 TTS 配置 ====================
# ✅ 复用上面的 COS 密钥
# TTS_SECRET_ID=  # 留空
# TTS_SECRET_KEY=  # 留空
TTS_ENABLED=true

# ==================== GitHub OAuth 配置（组长提供） ====================
# ✅ 使用组长提供的以下密钥（GitHub 登录功能）
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
# ⚠️ 本地开发保持此配置
FRONTEND_URL=http://localhost:5173

# ==================== 存储配置 ====================
STORAGE_MODE=local
LOCAL_STORAGE_PATH=../RG_data

# ==================== Python 配置 ====================
# ✅ Windows 系统保持 python 即可（确保已安装 Python 3.8+）
PYTHON_EXECUTABLE_PATH=python
VIDEO_GEN_SCRIPT_PATH=scripts/video_gen/generate_daily_video.py
```

## 🔑 API密钥申请指南

### SiliconFlow API（必需，自己申请）

**用途：** 视频生成中的AI文本生成（测试用例 F060-F076）

**申请步骤：**
1. 访问 https://siliconflow.cn/
2. 注册账号并登录
3. 进入"API密钥"页面 → 点击"创建新密钥"
4. 复制密钥填入 `backend/.env` 的 `SILICONFLOW_API_KEY`

💡 **提示：** 每个账号有免费额度，足够测试使用

### 豆包 API（必需，自己申请）

**用途：** 视频生成中的AI图像生成（测试用例 F060-F076）

**申请步骤：**
1. 访问 https://console.volcengine.com/ark/
2. 注册火山引擎账号并登录
3. 进入"模型API"页面 → 创建API密钥
4. 复制密钥填入 `backend/.env` 的 `DOUBAO_API_KEY`

💡 **提示：** 火山引擎也有免费额度

### 腾讯云COS & GitHub OAuth（组长提供）

这两个配置会通过**微信私聊**发送给大家，直接复制粘贴到对应位置即可。

⚠️ **重要：** 
- 不要泄露这些密钥
- 不要提交到Git仓库（`.env`已在`.gitignore`中）

## 1. 引言

### 1.1 产品概述

本产品是一款创新的背单词软件，旨在通过模仿“爱语境”等优秀应用的学习理念，结合智能化的学习和复习机制，帮助用户高效掌握单词。产品核心在于针对单词多义性的深度学习、情境化复习、个性化词书管理以及前沿AI技术的应用。**初期将以 Web 网站应用的形式进行开发和部署，用户通过浏览器即可访问。这为未来的多端同步和扩展奠定了基础。**

### 1.2 目标用户

主要面向需要提升英语词汇量、备考各类英语考试（如四六级、考研、雅思、托福）以及希望通过情境学习方式巩固单词记忆的**学生**。

### 1.3 产品目标

*   提供一种高效、有趣且符合记忆规律的单词学习体验。
*   帮助用户深入理解单词的多重含义，并在真实语境中运用。
*   支持用户个性化学习，满足不同词汇量和学习需求。
*   利用AI技术，提升学习的互动性和趣味性。

## 2. 功能需求

### 2.1 核心学习模块

#### 2.1.1 **【V3.0 说明】三路径引导式学习模型（继承 V2 并扩展）**

为提升学习效率与用户体验，将原有的单一学习流程升级为基于用户自我认知的三路径模型。此模型旨在精确匹配用户的认知状态，提供最高效、节奏稳定的学习路径。

* **学习单位:** 以**单词的单个词义**为最小学习和跟踪单位。
* **核心流程（针对每个新学词义）:**

    **步骤 1: 情境引入与自我认知判断**
    - **展示:** 系统展示包含目标单词的真题句或高质量例句（高亮目标单词）。
    - **交互:** 在句子下方提供三个选项，用户判断对该词义的初始认知状态：
        - **[ 我认识 ]**
        - **[ 感觉模糊 ]**
        - **[ 不认识 ]**

    **步骤 2: 进入差异化学习路径（精简版）**

    ---
    **路径 A: 我认识 —— “极速验证”**
    - **目的:** 快速证伪/确认，避免“知道错觉”。
    - **流程:**
        1) **超轻验证**（≤3 秒，二/四选一判断）。
        2) **结果:**
             - **答对:** 直接进入下一个词义（不再展示完整总结卡片，降低冗余）。
             - **答错:** 直接落入“路径 C”的教学卡片，同时记录一条**短期强化任务（Booster）**，默认间距10卡，稍后回访一次。

    ---
    **路径 B: 感觉模糊 —— “提取练习”**
    - **目的:** 通过一次标准提取练习激活并巩固不稳定记忆。
    - **流程:**
        1) **标准练习**（四选一/情境辨义）。
        2) **结果:**
             - **答对:** 展示**信息卡片**进行快速回顾，随后结束；轻反馈与要点高亮**显示 2 秒**。
             - **答错:** 直接展示信息卡片（不叠加“低压互动”），并记录**Booster**一条（默认间距10卡），稍后回访一次。

    ---
    **路径 C: 不认识 —— “教学优先”**
    - **目的:** 避免对无基础用户进行考试，先建立清晰表征。
    - **流程:**
        1) **教学卡片**（词义、音标、例句等）。
        2) **不叠加互动:** 不再追加第二种练习，节奏保持简洁。
        3) **轻量回访:** 记录**一次**Booster（默认间距10卡），回访时给**极简识别题**（二选一/判断）进行轻检索；
             - 回访答对：给**轻反馈 + 要点高亮 2 秒**，不展示完整总结卡片；
             - 回访答错：展示**简化教学卡片**，不再叠加互动。

    **Booster 次数上限（当日）**
    - 每个词义**当日最多 2 次**Booster（含由路径 C 触发的那一次）。若第 2 次仍失败，则不再入队，交由次日的 SRS 复习处理。

    **步骤 3: 学习下一个词义或单词**
    - 完成一个词义后，引导学习该单词的下一个词义；全部完成后进入单词总结页。

### 2.2 复习模块（含 SRS 与短期强化协同）

#### 2.2.1 多样化复习方式（基于掌握要求）

* **复习方式选择逻辑:**
    - **区分逻辑：** 依据单词在用户当前词书中的**掌握重点**匹配复习方式：
        - **recognition（识别）**：情境下的词义辨识/选择；
        - **production（输出）**：给义写词/听写，更强调拼写输出（仅对经人工确认的高频产出词启用）。
    - 复习阶段的评估采用**对/错二元判定**（无“模糊”按钮）。
    - 后期可优化：若出现“查看提示/超时”等情况，系统可内部标记为“模糊态”，用于策略调参，但对用户仍呈现对/错。
* **情境化复习:** 所有复习方式均在例句或真题句的情境中进行。

#### 2.2.2 艾宾浩斯记忆曲线功能（SM‑2 改进参数定稿）

* 系统**精确到词义**跟踪学习与复习，采用 **SM‑2 改进版**：
    - **初始 E‑Factor:** 2.5；**范围:** 1.3–3.0；
    - **最小间隔:** ≥ 1 天；
    - **第二次间隔:** 2 天（更适合中文学习者）；
    - **模糊（若被系统识别）:** 不重置，**维持间隔**；
    - **同日短期强化（Booster）:** 仅影响“今天”的巩固，不改写长期 `nextReviewAt`（长期计划由“当天首次有效评估”决定）。
* **掌握度 (`mastery_level`) 调整策略**：
    - 结合“三路径”与评估结果动态调整（0–5 级），并据此计算长期复习时间；
    - 首次评估为“错误”时，将间隔重置为 1 天；“正确”随 EF 增长而拉长间隔。

---

#### 2.2.3 短期强化（Booster）机制（定稿）

* **触发条件:**
    - **路径 A 错误**、**路径 B 错误**、**复习错误**均触发；
    - **路径 C**为保障生成效应，**固定触发一次**轻量回访（极简识别题）。
* **间距与上限:**
    - 默认间距：**忘记=5 卡**，**模糊/轻测=10 卡**；
    - 每个词义**当日最多 2 次**Booster；第 2 次仍失败则不再入队，交由次日 SRS 处理。
* **题型与反馈:**
    - 题型沿用触发时的题型与掌握重点；C 路径触发时采用**极简识别题**；
    - Booster 正确：**轻反馈 + 要点高亮 2 秒**，不再展示完整总结；
    - Booster 错误：展示**简化教学卡片**，不叠加互动。
* **统计口径:** Booster 不计入“今日新学/复习”的去重计数与百分比，仅用于当日巩固；如需调参，可在开发日志中记录，不落持久化表。

---

#### 2.2.4 播放调度与阶段策略（与稳定乱序配合）

* **阶段化播放（满足"先复习后新学"）**
    - **系统调度层面**：
        - **阶段 1：复习阶段**：只播放复习与其 Booster（到期优先），直至两者皆空；
        - **阶段 2：新学阶段**：只播放新学与其 Booster（到期优先），直至达到当日新学上限或队列为空。
    - **用户交互层面**：
        - **今日计划页面**提供两个独立入口：
            - **「开始复习」按钮**：启动 `review-only` 模式，仅复习到期词义；
            - **「开始学习」按钮**：启动 `new-only` 模式，仅学习新词义。
        - **柔性提示机制**：当用户点击「开始学习」但仍有待复习词义时，显示提示弹窗：
            - 提示内容："您还有 X 个单词待复习，建议先完成复习以巩固记忆。"
            - 提供两个选项：「去复习」（跳转到 review-only 模式）、「继续学习」（允许进入 new-only 模式）。
        - **设计理念**：通过 UI 引导而非强制，尊重用户自主选择，同时体现"先复习后新学"的最佳实践。
* **Booster 到期判定与先来先服务:**
    - 维护票据 `afterN`，每出一题全局 `step+1`，所有 `afterN-1`；
    - 新票据的 `afterN = 基础间距 + 当前未到期票据数`，同刻到期按生成顺序 FIFO，确保"先来先服务"。
* **稳定乱序（未学区间）**
    - 对“未学词义所属单词集合”按稳定哈希键排序：`hash(userId, wordId, salt_user_book)`；
    - **持久化 salt**（按“用户-词书”维度）以保证跨日/跨设备稳定；
    - "重乱序"仅更新 salt；已学/待复习不受影响,保障学习连续性。

#### 2.2.3 每日学习目标与复习优先策略 - **V3.1 优化**

为确保用户优先巩固已学内容，系统采用"复习优先"的每日目标管理机制。

*   **每日目标定义**:
    *   用户设置的 `daily_learning_goal`（默认 10）代表**新学习 + 复习的总完成数**。
    *   **目标计算公式**: `今日剩余配额 = 每日目标 - (今日已新学数 + 今日已复习数)`

*   **复习优先原则**:
    *   **复习无上限**: 用户可以无限制地进行复习，即使超出每日目标。
    *   **新学习受限**: 当 `(今日已新学数 + 今日已复习数) >= 每日目标` 时，系统阻止新词学习，但仍允许继续复习。
    *   **设计理念**: 复习是最重要的学习环节，应始终保持可用；新学习作为补充，在目标范围内进行。

*   **实施细节**:
    *   在 "新学模式" (`new-only`) 下，系统检查总完成数是否达到目标。
    *   如果达到目标，返回 "今日学习目标已完成" 消息，并设置 `isGoalReached: true`。
    *   在 "复习模式" (`review-only`) 下，无任何限制，用户可随时进行复习。
    *   在 "今日计划" API 中，`newLearningQuota` 计算考虑复习完成数：`Math.max(0, dailyGoal - (learnedToday + reviewedToday))`

*   **用户体验**:
    *   UI 清晰展示 "今日已完成 X/目标 Y"（X = 新学数 + 复习数）。
    *   当目标完成后，"开始新学" 按钮禁用，提示 "今日目标已达成，可继续复习"。
    *   "开始复习" 按钮始终可用（如有到期复习）。

### 2.4 AI 赋能模块

#### 2.4.1 每日学习视频生成 (Daily Learning Video) - **V3.0 新增**

为增强学习的趣味性和仪式感，系统利用 AI 技术为用户生成每日学习总结视频。

*   **功能概述**:
    *   系统根据用户**今日已完成学习的新单词**，自动生成一个包含这些单词的短视频。
    *   视频内容包括：单词拼写、释义、例句朗读、AI 生成的助记图片以及串联这些单词的微故事。
    *   支持中英双语字幕。

*   **选词策略**:
    *   **目标数量**: 固定 **7个单词**。
    *   **优先级**:
        1.  **今日已完成学习的新单词** (Today's Learned New Words)。
        2.  如果不足 7 个，从 **今日已复习单词** (Today's Reviewed Words) 中补齐。
        3.  如果总数仍不足 7 个，则使用所有可用单词。
    *   **前置条件 (V3.1 优化)**: 用户必须完成 **今日的学习或复习活动** 后才能生成视频。
        *   允许 **纯复习场景**：如果用户仅完成复习（未新学），也可生成视频。
        *   如果既无新学也无复习（`plan.progress.total === 0`），点击按钮时提示 "请先完成今日学习或复习"。

*   **生成限制与存储**:
    *   **每日限制**: 每日仅允许生成 **1次**。
    *   **重复点击**: 如果用户当日已生成过视频，再次点击按钮时，直接展示第一次生成的视频，**不触发**新的生成 API 调用。
    *   **存储策略**:
        *   仅保留 **当日** 生成的视频。
        *   系统每日凌晨自动清理（删除）昨日及之前的视频文件。
        *   数据库保留生成记录，但标记文件路径为已清理。

*   **用户界面 (UI/UX)**:
    *   **入口**: `HomePage` (今日计划/学习主页)，与“开始学习”、“开始复习”等按钮并列。
    *   **交互**: 点击生成 -> 进度弹窗 -> 自动跳转至全屏播放页面。

## 3. 数据库设计 (关联 Database_Design_Document_V3.md)

为支持新的学习模型和数据源策略，数据库设计已在 `Database_Design_Document_V3.md` 中进行对应升级。关键变更包括：
*   在 `words` 表中增加 `lemma` 字段，用于存储单词原型，以高效处理词形变化关系。
*   明确 `meanings` 表中的 `extra` 字段（原 `related_info`）用于存储英英释义、柯林斯星级等补充信息，与例句完全分离。
*   `example_pool` 表的设计将支持更丰富的元数据，如来源（真题/AI/ECDICT）、难度、匹配置信度等。
